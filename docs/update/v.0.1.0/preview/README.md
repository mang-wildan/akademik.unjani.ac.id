# Desain Panel Admin v0.10

Dokumen editable: `admin-panel.figcraft` (FigCraft). Berisi 69 frame dengan lebar 1440 px. Setiap frame punya PNG dengan nama yang sama di folder ini.

Gaya mengikuti landing (`docs/design/redesain-publik.figcraft`):

- **Warna:** latar ivory `#F4F1EA`, hijau UNJANI `#14532D` sebagai blok, dan aksen emas `#B8892B`.
- **Font:** Crimson Bold untuk judul, Swis721 BT untuk teks, dan Ubuntu Mono untuk label dan angka.
- **Elemen:** garis tipis, tanpa gradien atau glow.
- **Layout:** sidebar hijau 264 px (`adminNav`) dan topbar 64 px.
