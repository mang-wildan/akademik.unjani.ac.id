Catatan Penting Pengisian KRS & Pelaksanaan Ujian

Seluruh tahapan administrasi akademik berpedoman pada Buku Panduan Akademik UNJANI tahun berjalan. Mahasiswa diwajibkan menyelesaikan seluruh kewajiban keuangan sebelum batas akhir heregistrasi.
